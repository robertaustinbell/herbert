# Evidence

Preserve bounded source material, worked cases, and failures here. Evidence informs operating thought but does not govern merely by existing.

## Public source-retention boundary

Before copying full or substantial source material into this public repository, identify the named evidence purpose and verify that redistribution and continued retention are permitted by the source terms, privacy boundaries, and applicable policy. Retain only the minimum necessary material, cite precise provenance, and define when it should be reviewed or removed.

If the full source is unnecessary or not permitted for public retention, do not copy it here. Retain it privately only when a named review need, authority, source terms, privacy boundaries, and retention/disposal conditions all permit it; otherwise publish only a permitted citation or sanitized, minimum-necessary receipt. State coverage and availability limits; a URL, checksum, or provenance note does not mean the source itself remains available.

External field reports should begin with the privacy and evidence guidance in [`FIELD-TESTING.md`](../FIELD-TESTING.md). Do not copy private operational records into this directory.
